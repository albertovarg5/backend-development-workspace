# Git Reference Cheat Sheet

## Setup
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

## Daily Workflow
git status
git add .
git commit -m "message"
git push

## Branching
git branch
git checkout -b feature-name
git checkout main
git merge feature-name

## History & Inspection
git log --oneline
git diff
